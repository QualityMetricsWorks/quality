# Quality Summary — Beta 0.1.5

Portal web estático para monitoreo industrial de producción, scrap, PPM y Pareto 80/20.

## Beta 0.1.5

- Navegación superior: Dashboard, Captura, Clientes, Números de Parte, Catálogo e Historial.
- Diseño business/industrial con bordes más rectos y menor uso de sombras.
- Identidad corporativa: #EC6B1E, #143980 y #006732.
- Cliente reemplaza a Unidad de Negocio.
- Ficha interactiva por cliente con métricas y números de parte relacionados.
- Ficha interactiva por número de parte con métricas y defectos.
- Flujo Cliente → Número de Parte → Catálogo de Defectos.
- Tendencias de Scrap y PPM separadas.
- Pareto general 80/20.
- Top 3 productos con mayor scrap y Top 3 defectos de cada producto.
- Historial con búsqueda.
- Exportación Excel y respaldo CSV.
- Migración automática de datos de Beta 0.1.4 almacenados en localStorage.
